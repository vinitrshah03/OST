# 📊 Machine Learning Algorithms for Sales Prediction 🚀

Welcome to **Machine Learning Algorithms for Sales Prediction**! This repository contains various machine learning models implemented on a small dataset of **Tata Consultancy Services (TCS) from 2016-2023**, focusing on **sales, profit before tax, and profit after tax**. The primary objective is to predict **TCS's sales for the year 2024** using different ML techniques and compare their accuracy.

---

## 📊 Implemented Machine Learning Algorithms
This repository explores various ML algorithms for predicting sales:

1️⃣ **Single Linear Regression** 
2️⃣ **Multiple Linear Regression** 
3️⃣ **Polynomial Regression** 
4️⃣ **K-Means Clustering** 
5️⃣ **Principal Component Analysis (PCA)** 
6️⃣ **Combination of K-Means & Linear Regression** 
7️⃣ **Ridge & Lasso Regression**

Each model is used to predict **sales for 2024**, with an in-depth comparison of accuracy and performance.

## ⚙️ Requirements & Installation
To run the models, install the required dependencies:

```sh
# Clone the repository
git clone https://github.com/your-username/ML-Sales-Prediction.git
cd ML-Sales-Prediction

# Create a virtual environment (optional)
python -m venv venv
source venv/bin/activate  # On Windows use `.venv\Scripts\Activate.ps1`

# Install dependencies
pip install -r requirements.txt
```

## 🚀 How to Use
1️⃣ **Prepare the Dataset:** Since the dataset is small, it has been implicitly used in the code itself and no external CSV file needs to be downloaded or used.  

2️⃣ **Run the Models:**
- Execute the Python script for any algorithm in you IDE.
```sh
# Example: Running single linear regression
python single_linear_regression.py  
```

3️⃣ **Visualize Results:** The scripts generate a graph to help visualize the analysis. 

4️⃣ **Compare Accuracy:** For comparison of accuracy, each model is equipped with 'Metrics' for understanding the chances of error. For direct comparison, the data for 2024 is also provided at the start of the python script and also printed during on console as output for the user.
